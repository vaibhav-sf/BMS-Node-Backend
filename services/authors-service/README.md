# authors-service

This application is generated using [LoopBack 4 CLI](https://loopback.io/doc/en/lb4/Command-line-interface.html) with the
[initial project layout](https://loopback.io/doc/en/lb4/Loopback-application-layout.html).

It is an independent microservice that owns the `authors_db` PostgreSQL
database and exposes CRUD REST endpoints for authors. It runs on port `3002`
and does not share a database with `books-service` (which runs on `3001`).

## Install dependencies

By default, dependencies were installed when this application was generated.
Whenever dependencies in `package.json` are changed, run the following command:

```sh
npm install
```

To only install resolved dependencies in `package-lock.json`:

```sh
npm ci
```

## Configuration

Database connection settings are read from environment variables via `dotenv`.
Copy the values into a local `.env` file (which is git-ignored):

```sh
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=YOUR_ACTUAL_PASSWORD
DB_NAME=authors_db
PORT=3002
```

## Run the application

```sh
npm start
```

Open http://127.0.0.1:3002 in your browser.
